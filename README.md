# Retail Sales Data Analysis and Business Insights Using Python

## Project Overview
This project analyzes supermarket sales data using Python to understand sales performance, customer purchasing patterns, product category performance, and payment preferences. The goal is to identify useful business insights that can help improve sales and business decisions.

## Objectives
- Analyze supermarket sales data.
- Inspect and clean the dataset.
- Calculate important sales performance metrics.
- Compare sales across product lines and branches.
- Analyze customer payment preferences.
- Visualize sales trends and numerical relationships.
- Provide data-driven business recommendations.

## Dataset
The project uses a supermarket sales dataset containing transaction-level information.

- **Records:** 1,000 rows
- **Features:** 17 columns
- **Domain:** Retail and Sales Analytics
- **Data includes:** Product line, branch, city, customer type, gender, quantity, total sales, payment method, date, and customer rating.

## Technologies and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load the supermarket sales dataset.
2. Explore the dataset structure and summary statistics.
3. Check for missing values and duplicate records.
4. Clean the data and process date information.
5. Calculate key performance indicators (KPIs).
6. Analyze product line and branch sales.
7. Examine payment methods and transaction amounts.
8. Create visualizations to identify sales patterns.
9. Summarize findings and provide business recommendations.

## Key Performance Indicators
- Total Revenue
- Average Transaction Value
- Total Transactions
- Total Quantity Sold
- Average Customer Rating

## Visualizations
The notebook includes visualizations such as:
- Sales by Product Line
- Sales by Branch
- Payment Method Distribution
- Daily Sales Trend
- Transaction Amount Distribution
- Correlation Heatmap

## Expected Outcomes
This analysis helps identify high-performing product categories, compare branch performance, understand customer payment preferences, and recognize sales patterns. These insights can support inventory planning, promotional strategies, and business decision-making.

## Repository Files
- `Retail_Sales_Data_Analysis (1).ipynb` — Jupyter notebook containing the analysis, code, outputs, and visualizations.
- `cleaned_supermarket_sales.csv` — Cleaned dataset generated during the analysis.

## Conclusion
This project demonstrates how Python-based data analysis can transform retail transaction data into meaningful business insights. It applies data cleaning, exploratory data analysis, statistical summaries, and visualization techniques to support informed retail decisions.
